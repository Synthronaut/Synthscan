Modular installation: Choose the features you want. Live mining screen reading is an optional add-on.

SynthStrings: Makes game text more useful with clearer labels, blueprint ownership markers and additional mission information.

Reputation numbers: Shows your verified reputation points beside organization names, including the next rank’s threshold. In-game labels refresh after a full game restart.

Blueprint library: Search and organize blueprints, track ownership automatically from supported logs, and check off older unlocks manually.

Crafting information: View recipes, required materials, material-quality effects and known missions that unlock each blueprint.

Mining signature recognition: Reads visible rock signatures and identifies matching rock types.

Detailed rock breakdown: Displays readable material names, percentages, quality and estimated SCU for each material in a scanned rock.

Rock value estimates: Estimates unrefined sale value, refined sale value and player-market value using available prices.

Mining equipment advice: Compares mining heads and modules and helps assess whether your setup can break a rock.

Mining trip planner: Finds locations for selected materials, including possible overlaps and secondary ores.

Refinery yield planner: Compares estimated refined output and station bonuses before you commit an order.

Refinery records: Tracks supported work-order imports, completion notices and confirmed collections, with quantities and qualities.

Mining diary: Saves notable rocks and mining sessions, tracks personal records and creates shareable summaries.

Rock bookmarks: Saves and shares coordinates with shard information and return guidance.

Item & Ship Finder: Searches ships, equipment and items, with available stats, shop locations, prices and crafting links.

Player-market tools: Browses public UEX listings and saves material-and-quality watches for matching buyer advertisements.

Server HUD: Keeps your region, shard identity and last known location visible in a compact ribbon.

Server history: Records timestamped shard visits so you can review past sessions and recognize return visits while server hopping.

People tools: Searches player handles, shows reported shard members, highlights friends and party members, and supports custom tags, appearance alerts and selected-player social actions.

Missions HUD: Shows supported active contracts, available payouts, reputation rewards, estimated party splits and elapsed completion time.

Money and reputation ledger: Records observed aUEC and reputation changes alongside mission outcomes, durations and session summaries, with export options.

Piracy HUD: Provides a waiting timer and available interdiction-related log reports. It cannot reliably detect every catch.

Executive hangar timer: Shows the five-light configuration and estimated opening or closing countdown, automatically refreshing community timing and flagging outdated estimates.

Compboard inventory: Tracks all seven board types, counts complete sets and deducts a set when you claim a ship.

Day/Night Forecast: Estimates daylight, sunrise and sunset at supported destinations before you travel there.

Automatic acceptance: Optionally accepts supported contract shares, friend requests and party invitations, with separate controls for each.

Automatic chat hiding: Optionally hides global chat after joining a session.

AFK helper: Provides a HUD-accessible mouse-jiggler toggle; preventing the game’s inactivity timeout is not guaranteed.

Personal notes: Keeps routes, plans, reminders and session notes in a local notebook.

Adjustable HUDs: Switch between Mining, Piracy, Missions, Hangars and Finder; reposition, lock, dock or collapse the activity HUD.

Automatic startup and updates: Can launch alongside Star Citizen, check for app and reference updates, and rebuild supported game references after patches.

Local record storage: Keeps your saved ownership, notes, tags, inventories and history on your Windows account, without usage analytics.
